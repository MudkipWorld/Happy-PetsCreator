# Happy-PetsCreator
A Custom Pet creator for the old flash game Happy Pets. A part of the Happy Pets Restoration project!

### Purpose of this Project
This is a tool designed to help in the restoration of vanilla pets of the original game by allowing to recreate their data in the Happy Pets Restoration Project.       
This tool is also designed for the sandbox mode present in the project, which should allow players to create their own custom cats, dogs, etc.. (The currently supported/ found pets) and be able to import them into their local save       
Still in early development, so please keep that in mind.
